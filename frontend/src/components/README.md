# components

- `layout/`: app shell, sidebar, header and mobile layout.
- `campaigns/`: campaign composer, live view, the Marco panel and the image generation studio.
- `dashboard/`: dashboard widgets (sales cockpit, reactivation radar, B2B prospector, AI agents fleet, quick quote, competitor radar).
- `ui/`: design-system primitives (buttons, modals, tables, KPI cards, badges, daily briefing).
- `auth/RequireRole.tsx`: role gate for routes.
- `tour/`: guided in-app tour.
- `pwa/`: install prompt.
- Top level: `ChatBot.tsx` (see the known issue in the root README), `CommandPalette.tsx`, `KeyboardShortcutsModal.tsx`, `HotLeadsToast.tsx`, `ErrorBoundary.tsx`, `AuthenticatedImage.tsx`, `AuthenticatedFileLink.tsx`.
