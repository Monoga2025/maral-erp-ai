# pages

One file per screen. Main modules: `Dashboard`, `Clients` / `ClientDetail` / `ClientForm`, `Quotations` / `QuotationForm`, `Orders` / `OrderDetail` / `OrderForm`, `Whatsapp`, `Campaigns` / `CampaignWizard` / `CampaignLeads` / `CampaignReports`, `ImageLibrary`, `Production`, `Inventory`, `Purchases`, `Credit`, `Gastos` (expenses), `Tareas` (tasks), `Reports`, `Catalog` / `ProductForm`, `Tags`, `Settings`, `Manual` (in-app manual), `Login`.

`mobile/` holds phone layouts for dashboard, clients, quotations, orders, expenses and tasks.
