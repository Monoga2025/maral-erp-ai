# desktop

Small Windows helper written in C# (WinForms). It starts MARAL OS locally and shows a launcher window.

- `MaralOS_Launcher.cs`: launcher form.
- `Installer.cs`: installer source.
- `Guia_Don_John.html`: step-by-step user guide for a staff member.

Compiled `.exe` files are not included in this repository. Build them with a C# compiler.
