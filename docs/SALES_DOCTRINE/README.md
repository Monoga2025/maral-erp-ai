# SALES_DOCTRINE

The sales playbook that the WhatsApp and campaign features follow:

- `PSICOLOGIA_DECISION.md`: buyer decision psychology.
- `FRAMEWORKS.md`: sales frameworks in use.
- `TEMPLATES_GANADORES.md`: message templates that worked.
- `WHATSAPP_PLAYBOOK.md`: how to run WhatsApp conversations.
- `VOICE_AND_TONE.md`: tone guidelines for outgoing copy.
- `ANTI_PATTERNS.md`: phrasing and tactics to avoid.
