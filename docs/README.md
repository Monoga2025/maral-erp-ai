# docs

Project documentation, written mostly in Spanish.

- `ARCHITECTURE.md`: technical architecture (React SPA, Express API, PostgreSQL, EasyPanel deployment notes).
- `DOMAIN_MODEL.md`: entities and their relationships.
- `PROJECT_MASTER.md`, `ROADMAP.md`: scope and plan.
- `DEPLOYMENT_RACKNERD.md`: deployment runbook for a VPS host.
- `MARAL_MASTER_DATA_RECOVERY.md`: record of a data recovery run (process only, no records).
- `Live_Testing_Report.md`, `qa_context.md`, `AGENT_LOG.md`: testing notes and the agent work log.

Subfolders: `DECISIONS/` (ADRs), `HANDOFFS/` (per-area handoff notes), `MODULES/` (module specs), `REPORTS/` (QA and bug reports), `SALES_DOCTRINE/` (sales playbook), `SPRINTS/` (sprint plans), `USER_GUIDES/` (staff manual).
