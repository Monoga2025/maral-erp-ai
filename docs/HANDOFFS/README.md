# HANDOFFS

Handoff notes written at the end of each work session, one file per area: `backend-agent.md`, `frontend-agent.md`, `ui-agent.md`, `ops-agent.md`, `deployment.md`, and `john-meeting-2026-10-26.md` (follow-up actions from a stakeholder meeting).

They record what was done, what is pending and what was verified. Use them as a changelog of operational decisions, not as user documentation.
